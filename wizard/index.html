Create a WpApp

Generate a WordPress plugin scaffold powered by WpApp, optionally let an AI model build your app on top of it, then download it or run it in WordPress Playground — all in your browser.

Plugin

Used for the folder, main plugin file, text domain, and Composer package.

Setup Type
Build with AI (optional)

The model edits the scaffold using file tools and you can send follow-up prompts to refine it. Your prompt and the plugin files go directly to the provider you choose.

After Download

  1. Extract the zip file.
  2. Move the plugin folder into wp-content/plugins/.
  3. Activate the plugin in WordPress.
  4. Open the configured URL path.
WpApp runtime files are bundled into the Pages artifact and added to your zip with a Composer-lite autoloader.
