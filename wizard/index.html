Create a WpApp

Generate a WordPress plugin scaffold powered by WpApp and download it as a zip.

WpApp
Plugin

Used for the folder, main plugin file, text domain, and Composer package.

Setup Type

After Download

  1. Extract the zip file.
  2. Move the plugin folder into wp-content/plugins/.
  3. Activate the plugin in WordPress.
  4. Open the configured URL path.
WpApp runtime files are bundled into the Pages artifact and added to your zip with a Composer-lite autoloader.
